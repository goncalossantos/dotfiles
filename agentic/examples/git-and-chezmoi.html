What does a chezmoi template actually do?

The source name dot_claude/symlink_CLAUDE.md.tmpl tells chezmoi to create ~/.claude/CLAUDE.md as a symlink. The template inserts the local checkout path. The same Git source can therefore work when one machine uses ~/src/dotfiles and another uses /srv/config/dotfiles.

This prototype uses symlinks, so the checkout must remain in place. chezmoi can also deploy regular files instead of links.

What did we test?

On Linux/NixOS, nine Python installer tests and one real chezmoi 2.70.3 integration test passed. The tests used temporary homes. They covered dry runs, valid links, repeated apply, collision protection, arbitrary checkout paths, and removal or drift detection.

No authenticated agent session, macOS deployment, encryption, or secret-manager integration was tested. The seven-link chezmoi recipe is a working prototype, not a full dotfiles migration.

Check: if you only run git pull, are the clients configured?

Not on a new machine. You still need deployment into the clients' expected paths. On a machine already using our symlinks, pulled source edits become visible through those links; the clients may still need a reload or restart.
